# 🚀 E-Commerce Web Application (DOM-Driven)

A fully dynamic, front-end e-commerce application built entirely using core **JavaScript DOM manipulation** and enriched with fluid animations using **GSAP**. Every feature, from rendering layouts to handling state logic and user transitions, is managed programmatically without any external UI frameworks or libraries.

---

## 🛠️ Tech Stack Used

* **HTML5** — Semantic markup and structure
* **CSS3** — Custom layouts, responsive design, and core styling
* **JavaScript (ES6+)** — Dynamic DOM manipulation, state management, and core business logic
* **GSAP (GreenSock Animation Platform)** — Premium fluid animations and smooth UI transitions

---

## ✨ Key Features

### 1. Dynamic Men's Product Catalog
* Renders extensive product grids seamlessly from JavaScript data objects using pure DOM manipulation.
* Fully responsive layout handling product sorting and updates programmatically.

### 2. Interactive Product Detail Page
* Users can view targeted product insights, high-quality images, and dynamic data breakdowns upon item selection.

### 3. Detailed Product Description
* Structured breakdown of product fabrics, key highlights, patterns, and dynamic item specifications fetched in real-time from the state.

### 4. Real-time Pincode Checker
* Built-in validation functionality allowing users to check delivery availability instantly before proceeding to checkout.

### 5. Size Selection Logic
* Mimics real-world e-commerce user workflows by enforcing required size-selection attributes before unlocking the "Add to Cart" functionality.

### 6. Robust Cart Management
* **Add to Cart:** Dynamically pushes selected products and custom configurations (like size) into a centralized cart state.
* **Delete/Remove Items:** Users can instantly remove items from the cart wrapper with live UI updates and automated total price re-calculations.

### 7. Conditional Coupon System
* A smart discount system that allows users to apply promo codes. It dynamically recalculates order balances and lets users remove the coupon, rolling back prices based on specific cart conditions.
